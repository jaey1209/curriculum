# 교과서 선정대장 (교육과정부 업무 효율화 웹앱)

2027학년도 교과용 도서 선정 절차를 지원하는 정적 웹앱입니다. 별도 서버나 빌드 과정 없이
`web/index.html` 하나로 동작하며, 브라우저의 `localStorage`에 입력 내용을 저장합니다.

## 구성

- `web/index.html` — 앱 전체 (HTML + CSS + 바닐라 JS 단일 파일)

## 주요 기능

- **신청 입력**: 교과별 신청 내역을 표로 입력하거나 엑셀/구글시트에서 붙여넣기로 가져오기
- **교과별 평가 (교과부장용 도구)**: 후보 도서 평가표 (요소별 채점 / 순위 입력, 가격 점수 자동 환산)
- **자동 점검**: 제출·심의 전 필수 항목 누락, 중복·오기입 등 점검
- **교사 제출 점수**: 교과 교사가 만든 평가 코드를 교과부장이 취합
- **서식 생성**: 교과별 제출 서식, 학운위 심의안, 주문 집계, 교사별 확인표, 공개용 게시표를 자동 생성 (표 복사·CSV 다운로드)
- **절차 체크리스트**: 의견 수렴 → 안건 상정 → 심의 → 확정·공개 4단계 절차와 공정성 확인 사항
- **인쇄**: 헤더의 인쇄 버튼으로 인쇄용 레이아웃 출력. 교사가 과목 평가 화면에서 누르면 실제
  **[서식1] 검·인정도서 선정 평가표**(학교 hwpx 양식) 그대로의 레이아웃으로 인쇄됩니다.
- **2027학년도 고등학교 도서 목록 DB**: 교육청 공문 자료로 만든 검정·인정·국정 도서 1,172종
  (`web/index.html`에 내장) — 도서명·출판사 입력 시 자동완성 제안, 가격·도서구분 자동 채움,
  공식 목록과 다른 가격·목록에 없는 도서명을 자동 점검에서 경고

### 교사 화면 — [서식1] 평가

역할(교과 교사/교과부장)은 따로 고르지 않고, 입력한 성명이 교과부장 명단과 일치하면
자동으로 교과부장 화면으로 연결됩니다.

교사로 로그인하면 왼쪽 사이드바에 **2027학년도 선정 대상 과목**(교과별 고정 목록,
`SUBJECT_CATALOG`)이 모두 나열됩니다. 과목을 누르면:

1. 도서 목록 DB에서 해당 과목명과 일치하는 출판사·가격을 찾아 [서식1] 후보 칸에 자동으로 채웁니다
   (검정도서는 대부분 출판사·가격이 채워지고, 인정도서는 원본 목록에 출판사 정보가 없는 경우가
   많아 도서명만 채워지고 출판사·가격은 직접 입력해야 할 수 있습니다).
2. 점수를 매기기 전에 **① 항목별 점수 직접 입력** / **② 1위만 선정하기(점수 자동 채우기)** 중
   방식을 고릅니다. ②를 고르면 1위로 정한 출판사가 총점에서 가장 높게 나오도록 나머지 점수를
   무작위로 채우며, 이후에도 칸을 직접 고쳐 쓸 수 있습니다.
3. 후보(출판사) 수에 따라 평가표 열이 자동으로 늘어나거나 줄어듭니다.

교사가 채점 결과를 코드(또는 파일)로 만들어 교과부장에게 전달하면 교과부장 화면에서
취합·서식화합니다.

## 실행 방법

빌드가 필요 없습니다. `web/index.html`을 브라우저로 열거나, 정적 파일 서버로 서빙하면 됩니다.

```bash
cd web && python3 -m http.server 8000
# http://localhost:8000 접속
```

## 배포 (Google Apps Script)

`deploy/appsscript/`에 Google Apps Script 웹앱으로 배포하기 위한 파일과 단계별
가이드가 준비되어 있습니다. 자세한 내용은 [`deploy/appsscript/README.md`](deploy/appsscript/README.md)를 참고하세요.

## 법적 근거

절차 체크리스트와 공정성 확인 사항은 「교과용도서에 관한 규정」, 「초·중등교육법」을 참고 자료로
표시합니다. 실제 선정 절차는 소속 교육청의 해당 연도 선정 매뉴얼을 우선 확인해야 합니다.
