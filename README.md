# 교과서 선정대장 (교육과정부 업무 효율화 웹앱)

2027학년도 교과용 도서 선정 절차를 지원하는 웹앱입니다. 빌드 과정 없이 `web/index.html` 하나로
동작합니다. Google Apps Script 웹앱으로 배포하면 모든 선생님의 입력이 학교 Google 시트 한곳에
저장되고(아래 [데이터 저장](#데이터-저장)), 파일로 직접 열면 그 브라우저의 `localStorage`에만 저장됩니다.

## 구성

- `web/index.html` — 앱 전체 (HTML + CSS + 바닐라 JS 단일 파일)
- `deploy/appsscript/` — Google Apps Script 웹앱 배포 파일. `Code.gs`가 화면을 띄우고 입력 내용을
  Google 시트에 저장·불러오는 서버 역할을 합니다.
- `templates/form1.hwpx` — 학교 [서식1] 원본 한글 파일 (한글파일 저장의 바탕 틀)
- `tools/embed_hwpx_template.py` — 위 원본에서 글꼴·테두리·용지 설정 등을 뽑아
  `web/index.html` 안의 `<script id="hwpxTpl">` 블록에 넣는 도구. 원본 양식이 바뀌면
  `python3 tools/embed_hwpx_template.py` 실행 후 `deploy/appsscript/index.html`로 복사합니다.

## 화면 구성

역할(교과 교사/교과부장)은 따로 고르지 않습니다. 교과와 성명을 입력하면, 입력한 성명이
교과부장 명단(`DEPT_CHIEFS`)과 일치할 때만 교과부장 화면으로, 그 외에는 교사 화면으로
자동 연결됩니다.

### [서식1] 평가 — 교사·교과부장 공통

왼쪽 사이드바에 **자신의 교과에 배정된 2027학년도 선정 대상 과목**만 나열됩니다
(`SUBJECT_CATALOG`, 교과별 고정 목록 — 과목을 직접 추가·삭제할 수 없습니다). 출판사 자료가
없는 과목(교과서가 없어 선정하지 않는 과목, 예: 수학과제탐구·세계유산 탐구)은 목록에서 빠집니다.
과목을 누르면:

1. `SUBJECT_BOOKS`(교과부장이 취합한 교과+과목별 출판사·가격 자료)에서 해당 과목의 후보를
   찾아 [서식1] 후보 칸에 출판사·가격을 자동으로 채웁니다. 후보(출판사) 수에 따라 평가표
   열이 자동으로 늘어나거나 줄어듭니다.
2. 점수를 매기기 전에 **① 항목별 점수 직접 입력** / **② 1위만 선정하기(점수 자동 채우기)** 중
   방식을 고릅니다. ②를 고르면 1위로 정한 출판사가 총점에서 가장 높게 나오도록 나머지 점수를
   무작위로 채우며, 이후에도 칸을 직접 고쳐 쓸 수 있습니다.
3. 평가표 아래 **종합의견 및 추천의견** 칸에 의견을 씁니다(**필수**). 이 칸이 비어 있으면 제출되지
   않습니다. [서식1] 한 쪽에 들어가도록 4줄(약 250자)까지 쓸 수 있으며, 칸 아래에 글자 수와
   [서식1] 기준 줄 수가 표시됩니다.
4. **[제출]** 버튼을 누르면 지금까지 매긴 점수와 종합의견이 그대로 채워진 **[서식1] 검·인정도서 선정
   평가표**(학교 hwpx 양식 그대로의 레이아웃)가 생성되어 인쇄 화면으로 열립니다.
5. 제출한 과목의 **[제출 취소]** 버튼을 누르면 “입력 내용이 초기화 됩니다. 제출 취소하시겠습니까?”
   확인 후 점수·채점 방식·후보 목록·종합의견이 처음 상태로 돌아가고 상태가 **미작성**으로 바뀝니다.

사이드바의 상태 표시는 입력에 따라 바로 바뀝니다(미작성 → 작성중 → 완료 → 제출완료). ‘완료’는 점수와
종합의견을 모두 입력한 상태이며, 점수만 다 매긴 과목에는 “종합의견 필요”가 표시됩니다.
화면 상단의 **[서식1 생성]** 버튼을 누르면 ‘완료’ 과목 목록(종합의견이 없어 빠지는 과목도 함께)을
보여 주며 “[서식1] 생성하시겠습니까?”라고 확인한 뒤, 그 과목들을 한꺼번에 제출 처리합니다
(교과부장은 곧바로 [서식1] 탭으로 이동합니다).

확인 창은 브라우저 기본 창(confirm) 대신 화면 안에 띄웁니다. 기본 창은 미리보기처럼 다른 페이지 안에
끼워 넣은 화면에서 막혀 [제출 취소]가 아무 반응 없이 끝나는 일이 있었기 때문입니다.

**교과 교사**는 로그인하면 바로 이 화면으로 연결됩니다. **교과부장**도 자신의 교과 과목을
똑같이 평가해야 하므로, 상단 **[과목 평가]** 탭을 누르면 같은 사이드바·평가 화면이 그대로
열립니다 — 교과부장 전용 화면과 별개로, 자신의 평가표를 채우고 제출할 수 있습니다.

### 교과부장 화면

상단 탭으로 화면을 전환합니다.

- **과목 평가**: 위 [서식1] 평가 화면과 동일 (교과부장 본인의 평가 작성용).
- **서식1**: 교과 선생님들이 [과목 평가]에서 제출(또는 서식1 생성)한 [서식1] 검·인정도서 선정
  평가표를 모아 보여 줍니다(공유 저장소가 있으면 교과 선생님 전원의 제출분, 과목 순서대로 같은
  과목은 과 위원 이름 순). 출판사·가격·항목별 점수·합계·종합의견이 평가 내용에서 자동으로 채워지며,
  **서식 복사** 또는 **전체 서식 복사**로 한글에 붙여 넣을 수 있습니다. 자신의 교과 과목만 표시되고,
  ‘과 위원’ 칸에는 그 평가표를 제출한 사람의 성명이 들어갑니다. **[새로고침]**으로 방금 제출된
  것까지 다시 불러옵니다.
  이 탭에서는 헤더의 인쇄 버튼 대신 **[한글파일 저장]** 버튼이 보이며, 누르면 제출된 평가표 전체를
  학교 원본 양식(`templates/form1.hwpx`) 그대로 **한 장에 한 쪽씩** 담은
  `2027_서식1_{교과}.hwpx` 파일로 내려받습니다. Google Apps Script로 배포한 화면에서도 저장됩니다
  (Apps Script 웹앱은 다운로드를 허용함). Claude 미리보기 화면 안에서는 다운로드가 막혀 있어 저장되지
  않습니다.
- **서식2 · 서식3**: 추후 전달받을 hwpx 서식을 반영할 자리 (현재는 준비 중 안내만 표시).
- **절차 체크리스트**: 의견 수렴 → 안건 상정 → 심의 → 확정·공개 4단계 절차와 공정성 확인 사항.

교과부장은 **자신의 교과 데이터만** 봅니다. 평가표는 `교과|성명|과목`마다 따로 저장되므로,
같은 컴퓨터(예: 교무실 공용 PC)에서 여러 사람이 번갈아 로그인해도 서로의 평가가 섞이지 않습니다.

## 데이터 저장

교사마다 자기 컴퓨터에서 작업하므로, 입력 내용은 한곳에 모여야 합니다.

- **Google Apps Script로 배포한 주소에서 열면** 입력할 때마다 잠시 뒤 자동으로 학교 Google 시트
  (배포한 사람의 Google 드라이브에 자동으로 만들어지는 「교과서 선정대장 2027 데이터」)에 저장됩니다.
  다른 컴퓨터에서 같은 교과·성명으로 로그인하면 그대로 이어서 작업할 수 있고, 교과부장의 [서식1]
  탭에는 교과 선생님 전원의 제출분이 모입니다. 화면 위쪽에 `저장됨 12:03` / `저장 중…` /
  `저장 실패 · 다시 시도`가 표시되며, 실패하면 자동으로 다시 시도합니다(눌러서 바로 다시 시도).
  같은 사람이 두 곳에서 고치면 더 나중에 고친 쪽이 남고, 창으로 돌아오면 다른 곳에서 고친 최신
  내용을 불러옵니다. 교과부장의 절차 체크리스트도 교과마다 저장됩니다.
- 시트 **평가**에는 한 사람의 과목 하나가 한 줄(교과·성명·과목·상태·1위 출판사·종합의견·수정 시각)로
  보이므로 교육과정부에서 진행 상황을 바로 확인할 수 있습니다. 앱은 마지막 ‘자료(JSON)’ 칸을 읽으니
  시트에서 직접 고치지 마세요.
- **파일로 직접 열거나 미리보기 화면에서는** 서버가 없으므로 지금처럼 그 브라우저에만 저장되고, 화면
  위쪽에 `이 브라우저에만 저장`이 표시됩니다.

로그인은 교과·성명으로 구분할 뿐 별도 인증 장치가 아닙니다. 배포 주소를 아는 사람은 누구나 입력할 수
있으므로 주소는 교내에서만 공유하세요(학교 Google Workspace라면 ‘조직 내 사용자만’으로 배포 권장).

## 인쇄

헤더의 인쇄 버튼(또는 교사 화면의 [제출] 버튼)으로 현재 화면을 인쇄용 레이아웃으로
출력합니다. 교사가 과목 평가 화면에서 누르면 실제 **[서식1]** 레이아웃 그대로 인쇄됩니다.
교과부장의 [서식1] 탭에서는 인쇄 대신 위의 **[한글파일 저장]**을 씁니다.

## 실행 방법

빌드가 필요 없습니다. `web/index.html`을 브라우저로 열거나, 정적 파일 서버로 서빙하면 됩니다.

```bash
cd web && python3 -m http.server 8000
# http://localhost:8000 접속
```

## 배포 (Google Apps Script)

`deploy/appsscript/`에 Google Apps Script 웹앱으로 배포하기 위한 파일과 단계별
가이드가 준비되어 있습니다. 공유 저장소(Google 시트)를 쓰려면 이 방법으로 배포해야 합니다.
자세한 내용은 [`deploy/appsscript/README.md`](deploy/appsscript/README.md)를 참고하세요.

## 법적 근거

절차 체크리스트와 공정성 확인 사항은 「교과용도서에 관한 규정」, 「초·중등교육법」을 참고 자료로
표시합니다. 실제 선정 절차는 소속 교육청의 해당 연도 선정 매뉴얼을 우선 확인해야 합니다.
