# Google Apps Script 배포 가이드

`web/index.html`을 Google Apps Script 웹앱으로 배포하기 위한 준비 파일입니다.
Apps Script 프로젝트 생성·배포는 Google 계정 인증이 필요한 작업이라 이 저장소의
자동화 도구로는 대신 실행할 수 없습니다 — 아래 단계를 따라 직접 배포해 주세요.

이렇게 배포하면 선생님들이 각자 자기 컴퓨터에서 작업해도 입력 내용이 **배포한 사람의 Google
드라이브에 있는 스프레드시트 한곳**에 저장되고, 교과부장은 [서식1] 탭에서 교과 선생님 전원의
제출분을 모아 보고 한글 파일(.hwpx)로 저장할 수 있습니다.

## 포함된 파일

- `Code.gs` — 웹앱 진입점(`doGet`) + 저장소·로그인 역할. 화면에서 부르는 `apiLogin`(교사 코드 확인 →
  출입증 발급), `apiLoad`(내 평가 불러오기), `apiSave`(저장), `apiDeptForms`(교과부장 전용: 교과
  제출분 모아 보기)가 스프레드시트를 읽고 씁니다. 로그인 뒤 모든 요청은 출입증(서명한 토큰)의 교과·성명으로만
  처리되어, 교사는 자기 평가만, 교과부장은 자기 교과 결과만 볼 수 있습니다. 교과부장 명단은 `CHIEFS`.
  처음 불리면 스프레드시트 「교과서 선정대장 2027 데이터」를 만들고 그 ID를 스크립트 속성
  `SHEET_ID`에 기억합니다.
- `index.html` — `web/index.html`의 복사본 (Apps Script 프로젝트에는 확장자 없이 `index`로 올라갑니다)
- `appsscript.json` — 매니페스트. 웹앱을 **배포한 사람 권한으로 실행**(`USER_DEPLOYING`)하도록
  되어 있어, 선생님들에게 스프레드시트를 공유하지 않아도 앱을 통해서만 읽고 쓸 수 있습니다.

`web/index.html`을 수정했다면 이 폴더의 `index.html`도 같은 내용으로 다시 복사해 주세요.

## 방법 A — script.google.com에서 직접 (가장 쉬움)

1. [script.google.com](https://script.google.com)에서 **새 프로젝트** 생성
   (교육과정부 담당자 계정 등, 데이터를 보관할 계정으로 만드세요)
2. 기본 생성된 `Code.gs`의 내용을 이 폴더의 `Code.gs` 내용으로 교체
3. 왼쪽 **+** → **HTML** 파일 추가, 이름을 `index`로 지정 → 이 폴더의 `index.html` 내용을 그대로 붙여넣기
4. 왼쪽 프로젝트 설정(톱니바퀴)에서 **"appsscript.json manifest 파일을 편집기에 표시"** 를 체크한 뒤,
   나타난 `appsscript.json`을 이 폴더의 `appsscript.json` 내용으로 교체
5. 편집기 위쪽 함수 목록에서 **`setupSheet`** 를 골라 **실행** → 권한 요청 창에서 계정 선택 후 허용
   (스프레드시트를 만들고 읽고 쓰는 권한입니다). 실행 로그에 데이터 시트 주소가 나옵니다.
   이미 만든 적이 있으면 그 시트에 **교사** 탭만 새로 생깁니다.
6. 데이터 시트의 **교사** 탭을 열고, 「교사별 코드.xlsx」의 **이름·교과·코드** 세 열(머리줄 아래 35줄)을
   복사해 A2 칸부터 붙여 넣습니다. 이 명단에 있는 사람만 로그인할 수 있습니다. 코드는 이 시트에만
   두고 다른 곳에 올리지 마세요(교사가 바뀌면 이 탭만 고치면 되고 다시 배포할 필요는 없습니다).
7. 우측 상단 **배포 → 새 배포**
   - 유형: **웹 앱**
   - 다음 사용자 인증 정보로 실행: **나** (배포한 사람) — `appsscript.json`과 같아야 합니다
   - 액세스 권한이 있는 사용자: 학교 Google Workspace 계정이면 **조직 내 사용자만**(권장),
     개인 Gmail이면 **Google 계정이 있는 모든 사용자**
8. **배포**를 누르면 웹앱 URL이 발급됩니다. 이 URL을 교과부장·교사에게 공유하면 됩니다.
9. 이후 `Code.gs`/`index.html`을 수정하면 **배포 → 배포 관리 → 편집(연필 아이콘) → 버전: 새 버전**
   으로 갱신해야 같은 URL에 반영됩니다(새 배포를 만들면 URL이 바뀝니다).

## 방법 B — clasp CLI (로컬에서, 반복 배포가 잦다면)

```bash
npm install -g @google/clasp
clasp login                 # 브라우저에서 구글 계정 로그인
clasp create --type webapp --title "교과서 선정대장" --rootDir deploy/appsscript
clasp push                  # 이 폴더의 파일들을 Apps Script 프로젝트로 업로드
clasp open                  # 편집기가 열리면 setupSheet 를 한 번 실행 — 권한 승인·데이터 시트 생성
clasp deploy                # 웹앱으로 배포, URL 발급
```

이후에는 `deploy/appsscript/index.html`을 갱신하고 `clasp push && clasp deploy -i <배포 ID>`만
반복하면 됩니다.

## 데이터는 어디에 저장되나요

- 배포한 사람의 Google 드라이브에 있는 스프레드시트 「교과서 선정대장 2027 데이터」
  (주소는 `setupSheet` 실행 로그, 또는 스크립트 속성 `SHEET_ID`로 확인).
  - 시트 **평가**: 한 사람의 과목 하나가 한 줄 — 키(교과|성명|과목), 교과, 성명, 과목, 상태,
    1위 출판사, 종합의견 및 추천의견, 수정 시각, 자료(JSON). 앞쪽 칸은 사람이 보기 위한 요약이고
    앱은 마지막 ‘자료(JSON)’ 칸을 읽으니 **시트에서 직접 고치지 마세요**(보기·백업·필터는 괜찮습니다).
  - 시트 **교사**: 로그인 명단(이름·교과·코드). 교육과정부가 붙여 넣고 관리합니다.
  - 시트 **절차**: 교과부장 자료 — [서식3] 추천 의견(교과마다 한 줄).
- 이미 있는 스프레드시트를 쓰고 싶다면, 그 시트의 **확장 프로그램 → Apps Script**에서 위 파일을
  넣어 배포하면 그 스프레드시트에 저장됩니다(또는 스크립트 속성 `SHEET_ID`에 그 시트 ID를 넣기).
- 각 브라우저에도 사본이 남아 있어, 잠깐 연결이 끊겨도 입력은 사라지지 않고 연결되면 다시 올라갑니다.
  화면 위쪽의 `저장됨` / `저장 중…` / `저장 실패 · 다시 시도` 표시로 상태를 확인할 수 있습니다.

## (선택) AI 초안 — Claude API 키

과목 평가의 **AI 초안** 버튼은 키가 없어도 기본 초안을 넣어 줍니다. Claude가 쓰게 하려면:

1. [Claude Console](https://console.anthropic.com)에서 API 키를 만듭니다(사용량만큼 요금이 나갑니다).
2. Apps Script 편집기 → 프로젝트 설정(톱니바퀴) → **스크립트 속성** → 속성 추가:
   이름 `ANTHROPIC_API_KEY`, 값에 키를 붙여 넣고 저장합니다. 키는 이 속성에만 두고 화면이나 저장소에 넣지 마세요.
3. 편집기에서 `setupSheet`를 한 번 더 실행해 **외부 서비스 연결** 권한(UrlFetchApp)을 승인한 뒤, 새 버전으로 다시 배포합니다.

모델은 `Code.gs`의 `AI_MODEL`(`claude-opus-5`), 한 사람당 횟수 제한은 `AI_MAX_PER_HOUR`(1시간 30번)에서
바꿀 수 있습니다. 요청에는 과목·출판사·가격·항목별 점수만 들어가고 교사 이름·코드는 들어가지 않습니다.
안전 분류기가 요청을 거절하면 권장 모델로 자동으로 다시 시도하도록(`fallbacks: "default"`) 해 두었습니다.

## 한글 파일(.hwpx) 저장

Apps Script 웹앱은 화면을 샌드박스 iframe(`allow-downloads`, `allow-modals` 포함)에 띄우므로
[서식1]·[서식2]·[서식3] 탭의 **[한글파일 저장]** 으로 파일이 정상적으로 내려받아집니다. 확인 창도 화면 안에 직접
띄우므로 브라우저 설정과 관계없이 동작합니다.

## 보안 참고

- 로그인에는 교과·성명·교사 코드가 모두 맞아야 합니다. 코드는 시트 **교사**에만 있고 화면으로 보내지
  않으며, 한 사람이 코드를 5번 틀리면 10분 동안 로그인할 수 없습니다.
- 로그인하면 서명한 출입증(12시간, 쓰는 동안 연장)을 받습니다. 서명 비밀값은 스크립트 속성
  `TOKEN_SECRET`에 자동으로 만들어지며, 이 값을 지우면 모든 사람이 다시 로그인해야 합니다.
- 교사는 자기 평가만 읽고 쓸 수 있고, 교과 전체 제출분·[서식2]·[서식3] 자료는 그 교과의 교과부장만
  받습니다(서버에서 확인).
- 교사 코드는 세 자리 숫자라 추측을 완전히 막을 수는 없으니, 웹앱 URL은 교내에서만 공유하고 가능하면
  액세스 권한을 **조직 내 사용자만**으로 두세요. 스프레드시트 자체는 선생님들과 공유할 필요가 없습니다.
