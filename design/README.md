# 디자인 토큰 — B · Glass

Apple(macOS·visionOS) 유리 질감을 바탕으로 한 디자인입니다. 은은한 그라데이션 바탕 위에 반투명 카드를 올리고,
인디고로 강조하며, 버튼·탭은 알약 모양입니다. 값의 원본은 `web/index.html`의 `:root` 블록(라이트)과
`@media (prefers-color-scheme: dark)` / `:root[data-theme="dark"]` 블록(다크)이고, 컴포넌트 모양은 같은 파일 CSS 끝의
**디자인 B · Glass** 층에 있습니다.

- `tokens.json` — 토큰 정리본 (색상은 `light`/`dark` 두 값을 함께 가짐)

## 글꼴

- **Pretendard Variable** 한 가지로 제목·본문·숫자를 모두 씁니다(jsDelivr에서 불러옴). 불러오지 못하면
  Apple SD Gothic Neo(맥) / 맑은 고딕(Windows)으로 보입니다.
- 표의 숫자는 `tabular-nums`로 자리를 맞춥니다.

## 모양

- 모서리: 버튼·탭·칩 980px(알약), 카드 20px, 시작 화면 카드 26px, 입력 칸·목록 14px
- 카드: 반투명 `--surface` + `backdrop-filter: blur(24px) saturate(160%)` + `--glass-edge` 테두리 + `--shadow`
- 선택된 탭은 `--tab-on-bg`(라이트는 검정, 다크는 흰색)로 채웁니다.

## 바꾸지 않는 것

[서식1]·[서식2]·[서식3] 미리보기(`.deptform .dfbody`, `.f1tbl` 등)는 한글파일 양식과 같게 **흰 종이·검은 선**으로
둡니다. 다크 모드에서도 흰 종이로 보입니다.
