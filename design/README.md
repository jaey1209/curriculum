# 디자인 토큰 — Clear Glass (투명 유리알)

B · Glass의 색감(은은한 하늘·보라·청록 바탕, 인디고 강조)을 그대로 두고, 카드·버튼·탭을 속이 비치는
**투명한 유리알**로 만든 디자인입니다. 뿌연 흰 채움 대신 윗면 반사광·아래쪽 커스틱·흰 테두리로 유리 모양을 냅니다.
라이트 한 가지만 씁니다(다크 모드 없음).

값의 원본은 `web/index.html`의 `:root` 블록(색·글꼴)과 CSS 끝의 **디자인 B · Clear Glass** 층(유리 질감)입니다.
`tokens.json`은 그 정리본입니다.

## 유리 만드는 법

모든 유리 면은 네 겹입니다.
1. **채움** — 아주 옅은 흰색(.30, 버튼은 .14)이라 뒤가 비침
2. **윗면 반사광** — 위에서 아래로 빠르게 사라지는 흰 빛
3. **아래쪽 커스틱** — 바닥에 모이는 옅은 빛
4. **테두리·흐림** — 안쪽 흰 테두리(`--glass-rim`), `backdrop-filter: blur(16px) saturate(170%)`, 부드러운 그림자

유리알(`--bead`)은 위 반사광과 아래 커스틱이 있는 투명 구슬, 주 버튼(`--gem`)은 같은 빛을 반투명 인디고 위에 올린 것입니다.

## 글꼴·모양

- **Pretendard Variable** 한 가지(jsDelivr). 없으면 Apple SD Gothic Neo / 맑은 고딕. 숫자는 `tabular-nums`.
- 모서리: 버튼·탭·칩 980px, 카드 22px, 시작 화면 30px, 과목 목록 18px, 입력 칸 16px.
- 올리면 버튼·과목 카드가 1px 떠오릅니다(움직임 줄이기 설정이면 꺼짐).
