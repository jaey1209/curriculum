# 디자인 토큰 — Liquid Glass (유리알)

Apple Liquid Glass 느낌의 디자인입니다. 하늘·보라·분홍·청록 빛이 번진 바탕 위에 두껍고 맑은 유리 카드를 올리고,
버튼·탭·칩은 위쪽에 광택이 맺힌 유리알 모양입니다. 라이트 한 가지만 씁니다(다크 모드 없음).

값의 원본은 `web/index.html`의 `:root` 블록(색·글꼴)과 CSS 끝의 **디자인 B · Liquid Glass** 층(유리 질감)입니다.
`tokens.json`은 그 정리본입니다.

## 유리 만드는 법

모든 유리 면은 네 겹입니다.
1. **채움** — 반투명 흰색(왼쪽 위 .66 → 오른쪽 아래 .36)
2. **윗면 광택** — 위에서 아래로 사라지는 흰 빛(`--glass` 첫 겹)
3. **가장자리 빛** — 안쪽 1px 흰 선(`--glass-rim`)
4. **흐림·그림자** — `backdrop-filter: blur(28px) saturate(185%)` + 푸른 기가 도는 부드러운 그림자

유리알(`--bead`)은 위쪽 가운데에 빛이 맺힌 원형 그라데이션, 주 버튼(`--gem`)은 같은 광택을 인디고 위에 올린 것입니다.

## 글꼴·모양

- **Pretendard Variable** 한 가지(jsDelivr). 없으면 Apple SD Gothic Neo / 맑은 고딕. 숫자는 `tabular-nums`.
- 모서리: 버튼·탭·칩 980px, 카드 22px, 시작 화면 30px, 과목 목록 18px, 입력 칸 16px.
- 올리면 버튼·과목 카드가 1px 떠오릅니다(움직임 줄이기 설정이면 꺼짐).

## 바꾸지 않는 것
