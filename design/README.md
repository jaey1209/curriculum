# 디자인 토큰

`web/index.html`의 `:root` CSS 커스텀 프로퍼티에서 추출한 디자인 토큰입니다.
색상·타이포·여백·모서리 반경·그림자 값을 이름 붙여 정리했으며, 라이트/다크 테마를
모두 담고 있습니다.

- `tokens.json` — 토큰 원본 (색상은 `light`/`dark` 두 값을 함께 가짐)

## 색상 팔레트 요약

| 토큰 | Light | Dark | 용도 |
| --- | --- | --- | --- |
| `paper` | `#F3F5F0` | `#12150F` | 페이지 배경 |
| `surface` | `#FFFFFF` | `#1A1E17` | 카드·입력 배경 |
| `surface-2` | `#FAFBF8` | `#20251D` | 표 머리글, 보조 패널 |
| `ink` | `#171F1A` | `#E9ECE3` | 본문 텍스트 |
| `ink-2` | `#4A554D` | `#AEB7A9` | 보조 텍스트 |
| `ink-3` | `#7C877F` | `#7E887A` | 안내문, 비활성 |
| `line` | `#DBE0D6` | `#2F362B` | 테두리 |
| `line-2` | `#EBEEE7` | `#252B21` | 구분선 |
| `accent` | `#2F6B4F` | `#7DBF9A` | 강조(녹색) — primary 버튼, 선택 탭 |
| `warn` | `#9A5F22` | `#D6A469` | 경고 |
| `crit` | `#9E2F2F` | `#E08B85` | 오류/필수 |

## 타이포그래피

세 가지 서체 패밀리를 용도별로 나눠 씁니다.

- **Serif** (`Gowun Batang`) — 제목류 (h1, h2, 문서 제목)
- **Sans** (`IBM Plex Sans KR`) — 본문, 라벨, 안내문
- **Mono** (`IBM Plex Mono`) — 통계 숫자, 코드, 가격·점수 등 표 안 숫자

## 사용 방법

이 토큰은 문서용 정리본입니다. 코드에서 그대로 쓰려면 `web/index.html`의
`:root { ... }` 블록(라이트) 및 `@media (prefers-color-scheme: dark)` /
`:root[data-theme="dark"]` 블록(다크)이 실제 소스입니다 — 앱을 수정할 때는
이 문서가 아니라 그 CSS 변수를 고치고, 값이 바뀌면 이 문서도 함께 갱신하세요.
