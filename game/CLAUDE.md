# Claude 인수인계 · 먼저 읽어 주세요

## 목적
수원시 고등학교 최성보 담당 교사의 업무 역량 연수용 30분 목표 비주얼 노벨·육성 게임. 실제 나이스 접속 없이 가상 학생으로 진행합니다. 암기 정답보다 업무 프로세스, 동료 질문·보호자 문의에 대응하는 능력을 기르는 것이 목적입니다. 실제 플레이 시간 30분은 아직 참가자 측정으로 확정되지 않았습니다.

## 사용자가 확정한 방향
- 모바일 가로 화면 중심. 좁은 PC/세로 화면을 CSS로 강제 회전하지 않기. 큰 화면에서도 선택지 최대 약680px.
- 명조체 금지. 읽기 편한 고딕체, 큰 글씨, 전체화면 ON/OFF 및 Esc 상태 동기화.
- 첫 화면은 멘토 박수학. 과정부 소속이며 과정부장 아님. 키 정보 표시하지 않기.
- 닉네임만 직접 입력. 실습 숫자는 버튼 선택으로 입력하여 휴대전화 키보드를 띄우지 않기.
- 근거·출처 패널은 화면에서 제거한 상태 유지. 내부 기준·판정의 정확성은 유지할 것.
- 완료 후 복귀 문구는 ‘완료’. ‘이야기로 돌아가기’는 취소처럼 느껴지므로 쓰지 않기.
- 수기 검토 결과는 ‘이상 없음 / 수정 필요’.
- 대상자 가져오기로 자동 생성. 예정 인원 계산·입력 질문 없음.
- 학점당3시수는 시스템 기본값. 별도 적용 버튼 없음. 실제 참여시수 입력 후 이수/미이수 자동 표시. 저장은 조회 옆.
- ‘출석부 확인하기’ 사용. 누리의 초안 대조 문제·인수인계 메모·별도 결재 대기 퀴즈 제거.
- 김물리의 시간표·교실 배정 담당 설정 제거. 8명 학생 얼굴을 일관되게 사용. 학생 무대 크기는 교사보다 작게.
- 보호자 왼쪽 흰 말풍선, 주인공 오른쪽 파란 말풍선 및 이름 표시.
- 제한 시간·오답 감점·힌트 감점 없음. 자유 실습은 본편 기록·친밀도를 변경하지 않음.
- 책상 꾸미기 → 동료 반응 → 장 종료 짧은 특별 대화/선물 선택 → 기념사진 PNG 저장.
- 친밀도는 첫 업무 완료에서만 획득, 최대3. 재실행 중복 보상 금지. 친해지면 격려·말투와 출석부 미리 펼치기처럼 편의 지원. 행정 판정과 학생 이수 결과를 친밀도로 바꾸지 말 것.

## 고정된 행정 기준 및 가상 데이터
제공된 2026 경기도 자료를 우선. 서울시 자료는 Ⅰ·Ⅱ·Ⅳ장만 참고. 2025 구자료 수치를 2026에 섞지 말고 제도를 새로 만들지 마세요.
- 실제 시간표 수업 수51과 학점 기준량3×16=48을 구분. 출석 기준32회. 공통 과목 성취율40% 이상.
- 선택 과목에 성취율 기준을 적용하지 않음. 공통 두 기준 모두 미달은 보충지도 하나로 지원. 출석만 미달은 추가학습.
- 일반 예시 총 운영9시수, 참여6시수. 12시수 운영이면 참여8시수. 정규수업 부족시간만 채우는 것으로 바꾸지 말 것.
- 학생 판정: 나래 보충 / 다온 추가 / 마루 해당없음 / 라온 보충 / 가온 해당없음 / 누리 보충 / 다올 추가 / 여울 해당없음. 합계3/2/3.
- 실제 참여: 나래6, 라온5, 다온6(1·2·3·4·7·9차시), 누리9(전 차시 출석), 다올6(온라인5·6차시 포함). 누리9는 사용자의 2차 수정 요청으로 바뀐 최신값.
- 입력값의 이수 표시와 예외·학교 확인 절차를 혼동하지 말 것. 라온의 사실과 다른 시간을 더하지 말 것. 상담 선택은 학생의 행정 결과를 바꾸지 않음.
- 원점수를40점으로 바꾸지 않음. 대상0명도 반영·마감 확인. 저장·학점반영·교과마감·학생부반영·승인요청·결재완료 결과 확인은 구분.
- 실제 경기 나이스의 버튼 활성 조건·결재 권한·학교별 심의 절차는 미확인 사항을 단정하지 말 것. ‘학점반영자2’와 ‘이수자1’의 집계 의미는 원문 대조 필요.
